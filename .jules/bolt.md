## 2026-08-02 - Avoid Global Keydown Listener Churn in ProgressStepper
**Learning:** Adding a global keydown event listener inside a `useEffect` that depends on step state values (such as `currentStep`, `onStepClick`, and `steps.length`) causes the event listener to be constantly unbound and re-bound (churn) on every single questionnaire step transition. We can optimize this by storing the mutable state references in React `useRef` containers and keeping the `useEffect` dependencies restricted only to the event handler triggers themselves. This stabilizes the event listener subscription for the lifecycle of the component.
**Action:** Utilize React `useRef` to hold step references and callback definitions for global window/document event listeners. This separates the listener binding from state updates, preventing unnecessary event handler churn in high-frequency keyboard navigation UI elements.
