## User Story

**Title:** Add Interactive Gantt Charts for Visual Timeline Planning

**User Story:**
As a visual planner, I want interactive Gantt charts so that I can see my project timeline at a glance and adjust task dates by dragging.

**Acceptance Criteria:**

1. Display tasks on a timeline with start/end dates
2. Allow drag-and-drop to adjust task dates
3. Show task dependencies as connecting lines
4. Highlight critical path
5. Support zoom in/out (day/week/month views)
6. Export Gantt chart as image
7. Responsive design for mobile/tablet

**Value Justification:**

- Visual planners represent 30% of target users (founders, project managers)
- Gantt charts are the #1 requested feature in user research
- Differentiates IdeaFlow from text-only planning tools
- Enables better project tracking and deadline management
- Supports team collaboration by providing shared visual context
